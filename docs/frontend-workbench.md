# 前端工作台

## 视觉边界

事故档案工作区沿用会话、上传、表单及报告API。`src/workspace-layout.css`
承接已确认设计，`MaterialsWorkspace`负责本地待上传材料，账户组件共用
`src/account-workspace.css`。字体使用本机系统字体，不依赖远端字体下载；
各样式文件共用 `--font-sans` 令牌，不各自声明字体栈。字重只用400、500、600三档，界面最小字号12px。

颜色、阴影与圆角只在 `src/styles.css` 的 `:root`（浅色）和 `.theme-dark`（深色，挂在应用根与登录页根）
令牌中取值；组件只引用 `--color-*` 等语义令牌，不写字面色，也不为深色主题另写组件配色。
`--primary-color`、`--bg-subtle`、`--materials-*` 等旧名称只作别名。
页面使用中性工作面，蓝色表示主要操作，绿、琥珀及红配合文字说明状态；深色主题同为中性炭灰。
控件描边用 `--color-line-strong`，容器与分隔线用 `--color-line`。
工作区和章节不做多层浮动卡片，也不用装饰性渐变或光晕。圆角收敛为三档：控件6px、卡片与列表项8px、
浮层14px，头像用圆形；独立文件项属于卡片档。登录页样式独立在 `src/auth-screen.css`：品牌区为
`--color-brand` 深蓝纯色，只以线描的事故现场示意图作装饰（加载时两车驶入，减少动态时不播放），
流程与工作台阶段同名同序；表单直接置于页面表面、不套卡片，960px以下品牌区收为标题栏并以车道虚线收边。
表单为原生 `form`，回车提交，字段带 `autocomplete`，找回密码提示为信息而非错误。资料区主动作按钮高40px，
手机端底部提交按钮满宽且不低于44px；图标按钮保留明确的可访问名称。
报告正文与表格在自身区域内处理长内容，不撑宽整个页面。管理表的时间、结论徽标与反馈人为定长内容，固定列宽且不折行；
700px以下转为卡片，每格按表显式定位，分页控件放不下时整组换行。
事故字段采用随内容和可用宽度自动增高的多行输入，不通过裁剪长文本换取窄屏对齐。

页面水平边线按桌面32px、中屏24px、手机20px统一，页头、资料区、
管理控制台与模型配置共用同一条竖线。页头与下方滚动内容使用同一份滚动预留，
两者右边线一致；贴右边线的图标按钮做光学补偿，对齐的是图标墨迹而不是按钮盒。
档案抽屉内盒边线20px、文字与图标边线32px。

所有宽度默认隐藏档案导航，以覆盖抽屉打开；背景不可交互，Escape关闭后恢复焦点。
首页按整理资料、核对事实、查看报告组织，当前档案处理记录默认收起。
资料页只保留一层分类导航和一个素材工作面，手机分类横向滚动。
本地缩略图ObjectURL随资料移除及组件卸载释放；文件校验、分组清单和上传API不变。
事实编辑组件切换阶段时保持挂载，手机字段使用单列排版。
管理员首页与普通首页共用工作区，管理员额外显示用户及资料空间入口。
模型配置对两种角色开放，仅编辑现有vision、report、embedding能力；
密钥只显示掩码，留空保留，不提供没有后端契约的专家编辑或连接测试。
视觉与报告可另选推理等级，默认项显示服务端当前默认值；选“不发送该参数”时请求体不携带推理字段。
该项复用既有下拉控件，不新增样式，嵌入用途不显示。
每次只保存当前用途，成功后留在配置页，普通用户可依次完成视觉和报告配置。
账户与管理弹窗隔离背景，Tab保持在当前弹窗内，关闭后恢复原触发位置。
用户、资料空间或模型配置存在未保存草稿时，遮罩、关闭和取消操作必须先确认，不能静默丢弃。

## 交互契约

- 事故信息保存失败或冲突时，不创建或执行报告；已有编辑不能静默丢失。
- 失焦自动保存及会话普通更新也携带服务端版本；保存失败阻止离开当前会话，后台失败显式记录而不吞掉前台错误。
- 模型配置读取失败时展示错误，但当前不会因此直接禁用生成；提交后仍可能由后端拒绝。运行服务不可用时不回退到不受控的旧生成链路。
- 材料来源、位置与内容必填；生成期间禁用修改，保留每份运行的证据快照。
- 连续点击生成或取消只触发一项对应操作；停止请求在等待时不可重复点击。
- 当前档案生成或写入报告操作未完成时，阻止新建、切换、删除档案及退出登录；报告记录读取失败本身不锁住导航。
- 资料详情及关联产物预览隔离背景，Tab约束在弹窗内部，关闭后恢复触发位置。
- 顶部和报告区共享真实运行状态；读取或保存材料不冒充报告生成，取消等待时两处停止按钮同步禁用。
- 报告记录读取失败不显示“尚未生成”，需重新读取成功后才能生成；取消和导出重试清除旧错误。
- 未知请求的确认只使用一次，切换运行或状态版本即清空。
- 正式下载取决于服务端发布资格，开发报告不能因为前端样式或状态文字取得该资格。下载入口按运行的 `export_kind` 显示，工程稿与未通过审查的候选稿附标记说明。
- 报告页末尾提供质量反馈（总体结论、问题类型、具体意见、反馈人）；管理控制台“质量反馈”页汇总各报告最新意见并导出表格。
- 图标按钮保留可访问名称及悬停提示，焦点可见；不可操作控件同时提供原生禁用状态。
- 手机分类栏由导航元素自身横向滚动，不把宽度设成内容宽度；右侧渐隐提示不拦截横向滑动，仅箭头图标可点。
- 会话标题为原生按钮，支持键盘进入；同步失败和业务错误通过警告区域公告。
- 明确显示登录username，不用显示名称或固定昵称替代。事实区提供显式保存及保存状态，确认前先完成保存。
- 增强报告组件的显示和证据/运行记录 API 读取由 `enabled` 控制；`online_enabled` 只控制是否进入正式在线运行路径。`enabled=true`、`online_enabled=false` 时仍可使用增强组件；原报告路径保持可用。

## 验证

在`frontend`目录执行`npm test`和`npm run build`。
`node tests/workspace-browser.mjs`运行真实React界面并拦截HTTP返回合成样例，
验证两种角色在1440、1024、768、390、320下的导航、上传请求、事实保存、管理页及配置入口，
包括保存按钮遮挡、管理表与质量反馈单元格越界及短字段折行、分页折行和禁用增强能力零请求断言，
截图前等待有限过渡结束，不调用真实模型。
开发服务器默认地址为`http://127.0.0.1:15175`，可用`WORKSPACE_TEST_URL`覆盖；
`WORKSPACE_TEST_OUTPUT`指定截图及结果目录，不设置时使用本机临时目录。
`tests/integrated-report-scenario.mjs`通过真实浏览器、HTTP及隔离PostgreSQL检查原页面，
覆盖补证、生成、历史、取消、未知确认和配置失败；由`HARNESS_INTEGRATED_UI_TEST=1 node tests/harness-e2e.mjs`
启动，合成账号预置视觉与报告模型的回环占位配置，控件尺寸按可点区域（含包裹复选框的标签）计量。
视觉回归检查1440、1024、768、390、320宽度，检查主按钮边界、高度、手机内容包含关系和横向溢出，
并保留截图供人工与代理复核。合成模型的组件或浏览器测试不代表真实模型报告质量。
另以37个事故字段及长文本检查桌面和320px窄屏输入不越出单元格且全文可见，
每个输入都有对应字段的可访问名称；停止请求等待期间和生成期间分别检查按钮位置及重复点击。

三阶段工作区设计沿用本机kimi-code/k3-256k与Claude Code的frontend-design技能协作产物；
对齐、圆角、字体、边线与颜色令牌（含深色主题）的统一由Claude Code的frontend-design技能按浏览器实测完成。
两轮均不发送私有事故材料、凭据或服务器配置。设计原型测试不代替实际组件或服务端验收。
